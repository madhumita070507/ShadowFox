# ShadowFox
this is my documentation of the internship I completed in shadowfox.
task-1:
Beginner level task was to pre-process a dataset and predict the values. I used random forest to predict the housing price and evaluated the model using normal evalution metrics.
task-2:
Intermediate level was to analyse the dataset using python and find trends. Using these trends we were supposed to give insights on how to improve the domain.This was very new to me so I got some help from youtube and chatgpt. This was very informative and I learnt about many libraries and business patterns and evaluation techniques.
task-3:
The advanced level task was generative-AI. Used GPT-2 and gradio to make a simple text generator. Felt it was too simple so I had some help from chatgpt to help me with building a text generator which will generate text using a selected emotion. Gradio was new to me so I had to have some help from gpt. The evaluation was done using perplexity and bleu and visualisation was executed too.
